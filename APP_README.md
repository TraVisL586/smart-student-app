# Smart Student – App

Bản web app đã được chuyển thành **PWA (Progressive Web App)**, có thể cài lên Android/iPhone như một ứng dụng từ trình duyệt.

## Chạy app

```bash
npm start
```

Mở `http://localhost:3000` trên máy tính hoặc điện thoại cùng mạng.

## Cài trên Android

Mở app bằng Chrome → menu `⋮` → **Cài đặt ứng dụng / Add to Home screen** (tên có thể khác tùy phiên bản Chrome).

Sau khi cài, Smart Student mở ở chế độ app riêng và có icon trên màn hình chính.

## Lưu ý AI

AI thật cần `OPENAI_API_KEY` trên server. Không đưa API key vào file frontend.
